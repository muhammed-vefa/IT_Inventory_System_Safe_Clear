# IT Inventory Management System

Bu proje, orta ve büyük ölçekli kurumlarda (hastaneler, veri merkezleri vb.) bulunan Bilişim Teknolojileri (IT) donanımlarının ve ağ altyapı cihazlarının takibini otomatize etmek amacıyla geliştirilmiş kapsamlı bir **Demirbaş ve Envanter Yönetim Sistemidir**.

## 🚀 Projenin Amacı ve Özellikleri

Manuel donanım takibinin ve Excel tablolarının zorluklarını ortadan kaldırmak için tasarlanan bu sistem, IT uzmanlarının donanım yaşam döngüsünü profesyonelce yönetmesini sağlar.

- **Kapsamlı Envanter Takibi:** Bilgisayar, sunucu, switch, yazıcı ve medikal IT cihazlarının kayıt, zimmet ve lokasyon takibi.
- **Güçlü Veritabanı:** Güvenli ve hızlı veri işleme altyapısı.
- **Otomasyon ve Scripting:** Veri temizleme, sistem başlatma ve manuel yedekleme süreçlerinin `.bat` dosyalarıyla (Windows Batch Scripting) tamamen otomatize edilmesi.
- **Raporlama ve İzleme:** Sistemdeki cihazların durumu hakkında raporlar (reports) ve log (monitoring) kayıtları oluşturma.
- **Kullanıcı Dostu Arayüz:** JavaScript, HTML ve CSS kullanılarak tasarlanmış, kullanımı kolay web arayüzü (Frontend).
- **Backend Mimarisi:** Python altyapısı ile stabil çalışan güçlü arka uç servisleri.

## 🛠️ Kullanılan Teknolojiler

- **Backend:** Python
- **Frontend:** HTML5, CSS3, JavaScript
- **Veritabanı ve Sunucu Yönetimi:** SQL Server, SFTP
- **Sistem Otomasyonu:** Windows Batch Scriptleri (.bat), Git
- **Güvenlik Mimarisi:** Çevresel değişkenlerle (Environment Variables) izole edilmiş güvenli yapı.
